### 1. AI Learning Companion

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/chandraPrakash-tripathi/AI_LEARNING_COMPANION) [![Live Demo](https://img.shields.io/badge/Live-Demo-FF4B4B?style=flat&logo=streamlit&logoColor=white)](https://learncomm.streamlit.app/)

An interactive ML learning platform designed to make machine learning concepts easier to understand through visualizations and experimentation.

- Interactive gradient descent visualization.
- Activation function playground with mathematical explanations.
- Machine learning model comparison dashboard.
- Separate frontend and backend architecture.
- CI/CD workflows using GitHub Actions.

**Tech Stack:** Python, Streamlit, Flask, Scikit-learn, NumPy, Pandas, Matplotlib.

### 2. Sign Language Recognition System

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/chandraPrakash-tripathi/Sign-language-mediapipe)

- Hand landmark detection and feature extraction using MediaPipe.
- Machine learning-based gesture recognition.
- Integration with sensor-based smart glove hardware.
- Real-time sensor data processing and recognition.

**Tech Stack:** Python, MediaPipe, Machine Learning, Raspberry Pi, Firebase.
